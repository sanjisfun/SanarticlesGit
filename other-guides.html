⚙️ Продвинутые техники Git

🔍 Git bisect

Автоматический поиск коммита, внесшего баг.

git bisect start
git bisect bad HEAD
git bisect good a1b2c3d
# тестируем, помечаем git bisect good/bad
git bisect reset

🔄 Git worktree

Работа с несколькими ветками одновременно в разных директориях.

git worktree add ../hotfix hotfix-branch
cd ../hotfix
# работаем
git worktree remove ../hotfix

🧹 Очистка истории: BFG Repo-Cleaner

java -jar bfg.jar --delete-files *.log --delete-folders secrets repo.git
git reflog expire --expire=now --all
git gc --aggressive --prune=now

📌 Git Submodules и subtrees

Подключение внешних репозиториев:

git submodule add https://github.com/user/lib.git
git submodule update --init --recursive
# или subtree (встроенный код)
git subtree add --prefix=lib https://github.com/user/lib.git main --squash

⌨️ GitHub CLI (gh) — продвинутое использование

# установка (macOS)
brew install gh
gh auth login

# Создать issue с метками
gh issue create --title "Bug" --body "описание" --label "bug"

# Создать PR с автоматическим ревьюером
gh pr create --title "Feature" --body "..." --reviewer user1,user2

# Клонировать репозиторий и перейти в него
gh repo clone user/repo -- --depth=1

# Запустить workflow вручную
gh workflow run ci.yml --ref main -f environment=staging

# Просмотр статистики репозитория
gh api repos/user/repo/community/profile

⚡ GitHub Actions: матрицы, артефакты, среды

Матрица с переменными окружения

jobs:
  test:
    runs-on: ${{ matrix.os }}
    strategy:
      matrix:
        os: [ubuntu-latest, windows-latest]
        node: [16, 18, 20]
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: ${{ matrix.node }}
          cache: 'npm'
      - run: npm ci
      - run: npm test

Сохранение и загрузка артефактов

- uses: actions/upload-artifact@v4
  with:
    name: dist
    path: dist/
- uses: actions/download-artifact@v4
  with:
    name: dist
    path: ./download

Ручной запуск с окружениями и защитой веток

on:
  workflow_dispatch:
    inputs:
      environment:
        type: environment
        description: 'Выберите окружение'
        required: true
jobs:
  deploy:
    runs-on: ubuntu-latest
    environment: ${{ github.event.inputs.environment }}
    steps:
      - run: echo "Deploy to ${{ github.event.inputs.environment }}"

🛡️ GitHub Security: углубленно

Dependabot + группы обновлений

# .github/dependabot.yml
version: 2
updates:
  - package-ecosystem: "npm"
    directory: "/"
    schedule:
      interval: "weekly"
    groups:
      production-dependencies:
        patterns: ["*"]
    ignore:
      - dependency-name: "lodash"
        versions: [">=5.0.0"]

CodeQL — расширенная настройка

- name: Initialize CodeQL
  uses: github/codeql-action/init@v3
  with:
    languages: javascript, python
    queries: security-extended, security-and-quality
- name: Perform CodeQL Analysis
  uses: github/codeql-action/analyze@v3
⚠️ Включите secret scanning в настройках репозитория → Security → Enable secret scanning. Добавьте пользовательские шаблоны для внутренних токенов.

📦 GitHub Packages: реестр артефактов

Храните Docker-образы, npm-пакеты, Maven, NuGet прямо в GitHub.

Публикация npm-пакета через Actions

- name: Publish to GitHub Packages
  run: npm publish
  env:
    NODE_AUTH_TOKEN: ${{ secrets.GITHUB_TOKEN }}

Сборка и публикация Docker-образа

- name: Log in to GitHub Container Registry
  uses: docker/login-action@v3
  with:
    registry: ghcr.io
    username: ${{ github.actor }}
    password: ${{ secrets.GITHUB_TOKEN }}
- name: Build and push
  uses: docker/build-push-action@v5
  with:
    push: true
    tags: ghcr.io/${{ github.repository }}:latest

🏗️ Управление монорепозиториями и масштабирование

Инструменты: Git Submodules, git subtree, Nx, Turborepo. Пример стратегии с Actions для монорепозитория:

on:
  push:
    paths:
      - 'packages/backend/**'
      - 'packages/frontend/**'
jobs:
  changes:
    runs-on: ubuntu-latest
    outputs:
      backend: ${{ steps.filter.outputs.backend }}
      frontend: ${{ steps.filter.outputs.frontend }}
    steps:
      - uses: dorny/paths-filter@v3
        id: filter
        with:
          filters: |
            backend: 'packages/backend/**'
            frontend: 'packages/frontend/**'
💡 Используйте Git LFS для бинарных ассетов. Настройка:
git lfs track "*.psd" "*.zip"
git add .gitattributes
git commit -m "track large files"

🗣️ GitHub Discussions & Community Health

Активируйте Discussions в настройках репозитория. Создайте шаблоны категорий: Q&A, Ideas, Announcements.

# .github/ISSUE_TEMPLATE/config.yml
blank_issues_enabled: false
contact_links:
  - name: Обсуждение на форуме
    url: https://github.com/org/repo/discussions
    about: Задайте вопрос в Discussions

Автоматическое приветствие новых участников через Actions:

name: Welcome
on:
  issues:
    types: [opened]
jobs:
  welcome:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/first-interaction@v1
        with:
          repo-token: ${{ secrets.GITHUB_TOKEN }}
          issue-message: "Спасибо за issue!"

📊 GitHub Insights, метрики и API

Получение статистики через REST API:

# трафик репозитория
curl -H "Authorization: token YOUR_TOKEN" \
  https://api.github.com/repos/octocat/hello-world/traffic/views

# топ контрибьюторов
curl -H "Authorization: token YOUR_TOKEN" \
  https://api.github.com/repos/octocat/hello-world/stats/contributors

Используйте GitHub Actions для автоматической публикации отчётов в Discussions.
