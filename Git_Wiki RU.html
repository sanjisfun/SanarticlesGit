Что такое GitHub

GitHub — облачная платформа для размещения git-репозиториев, совместной разработки, обзора кода (pull requests), управления задачами (issues) и автоматизации CI/CD с помощью Actions. Подходит для личных проектов, команд и предприятий.

Ключевые функции

  • Репозитории: код, история и версии.
  • Ветвление и Pull Requests: кодовые ревью и обсуждения.
  • Issues & Projects: планирование и управление задачами.
  • Actions: автоматизация CI/CD и deployment.
  • Security: Dependabot, secret scanning, проверки кода.
  • Pages & Wiki: хостинг документации и статических сайтов.

Как загружать файлы — варианты и сравнение

СпособКогда использоватьШаги (сокращённо)
Веб-интерфейс Мелкие правки, README, одиночные файлы Repo → Add file → Upload files → Commit
Git (локально) Полноценная разработка, история, ветки git init/clone → add/commit → remote add → push
GitHub CLI (gh) Терминал-ориентированные workflow, PR/issue из CLI gh auth login → gh repo create → git push
Git LFS Большие бинарники (>100MB) git lfs install → git lfs track → add/commit → push

Подробные инструкции

Через веб

  1. Создать репозиторий: GitHub → New repository → имя + visibility + Init README (опционально).
  2. Загрузить: Add file → Upload files → перетащить или выбрать → Commit.

Через Git (рекомендуемый)

# инициализация и первый коммит
git init
git add .
git commit -m "Initial commit"

# подключить удалённый и отправить
git remote add origin https://github.com/USERNAME/REPO.git
git branch -M main
git push -u origin main

GitHub CLI

gh auth login
gh repo create my-repo --public --source=. --push

Git LFS (если нужно)

git lfs install
git lfs track "*.bin"
git add .gitattributes
git add bigfile.bin
git commit -m "Add large file"
git push

Пример рабочего процесса и пример GitHub Actions workflow

Упрощённый Git flow

  1. main: стабильная ветка, релизы.
  2. feature/*: разработки фич.
  3. PR: открыть pull request → ревью → CI → merge.
  4. Release: tag и deploy из main.

Пример .github/workflows/ci.yml

name: CI

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  build-and-test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Setup Node
        uses: actions/setup-node@v4
        with:
          node-version: '18'
      - run: npm ci
      - run: npm test
        env:
          CI: true

Лучшие практики

  • Малые коммиты: делайте понятные и атомарные изменения.
  • Читабельные сообщения: описывайте «почему», а не только «что».
  • .gitignore: не храните временные файлы и секреты.
  • Secrets: используйте GitHub Secrets для CI.
  • Авто-тесты: запускайте тесты в Actions на каждый PR.

Безопасность

  • 2FA: обязательно включить двухфакторную аутентификацию.
  • Dependabot: автоматические обновления зависимостей.
  • Code scanning: статический анализ и secret scanning.
  • Правила ветвления: protected branches и required reviews.

Ресурсы и шпаргалка

  • Официальный Git — команды и концепции.
  • GitHub Docs — справочник по функционалу.
  • Actions Marketplace — готовые шаги для workflow.
